# 💎 Bence Internet Pro

Üdvözlünk a **Bence Internet Pro** hivatalos GitHub oldalán! 

Ez a Bence Internet haladó kiadása, amely az alapverzió minden funkciója mellett exkluzív, prémium szolgáltatásokat kínál a felhasználóknak. A böngésző az **NW.js** (Chromium motor) segítségével készült.

---

## 💎 Pro funkciók (Az alapverzióhoz képest)

- 🌙 **Sötét mód (Dark Mode):** Gyönyörű, sötét kék-lila téma, amely kíméli a szemet és modern megjelenést kölcsönöz.
- ⭐ **Könyvjelző mentés:** A címsor melletti csillag ikonnal egy kattintással elmentheted a kedvenc oldalaidat, amiket a böngésző meg is jegyez a következő indításig.
- ↩️ **Bezárt fülek visszanyitása:** Ha véletlenül bezárnál egy fület, a `Ctrl + Shift + T` gyorsgombbal visszahozhatod.
- ⬇️ **Letöltések menü:** Átlátható panel a folyamatban lévő és befejezett letöltésekhez (Ctrl + J).

---

## ✨ Alapfunkciók

- **Modern, Chrome-szerű felület** fülsávval és okos címsorral.
- **Több fül kezelése** (nyitás, zárás, váltás).
- **Beépített kezdőlap** keresővel és gyorslinkekkel.
- **Keresés az oldalon** (Ctrl + F).

---

## 🚀 Telepítés és futtatás

### Legegyszerűbb mód (Windows)
1. Lépj a jobb oldali **Releases** (Kiadások) fülre.
2. Töltsd le a `BenceInternetPro.exe` fájlt.
3. Kattints duplán a letöltött fájlra, és már indul is a böngésző!

### Futtatás forráskódból (Fejlesztőknek)
1. Töltsd le az [NW.js](https://nwjs.io/) SDK verzióját.
2. Klónozd ezt a repository-t.
3. Csomagold ki az NW.js-t, és másold a mellé a projekt fájljait (`index.html`, `home.html`, `package.json`, `icon.png`).
4. Indítsd el az `nw.exe`-t.
